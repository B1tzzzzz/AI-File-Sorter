━━━ ЧТО ИСКАТЬ ━━━

ТОЛЬКО следующие проблемы. Не придирайся к мелочам, не предлагай
новые верхние категории, не трогай имена файлов.

1. ДУБЛИ ПАПОК (type: "merge")
   "Nature/" и "Natural/", "Wildlife/" и "Animals/Wildlife/",
   "Urban/" и "City/".
   → from → to

2. ПЕРЕИМЕНОВАНИЕ ПАПКИ (type: "rename_folder")
   Папка называется неудачно, но её смысл верен:
   "Nature/AutumnScene/" → "Nature/Autumn"
   → from → to

3. ПЕРЕНОС ГРУППЫ ФАЙЛОВ (type: "move_files")
   Группа файлов из одной папки должна переехать в другую:
   "Technology/Queue/" (3 файла) → "Technology/Computing"
   → from_folder, to_folder, files: ["a.txt", "b.txt", ...]

4. СЛИШКОМ УЗКИЕ ПАПКИ (type: "too_specific")
   Папка с 1–2 файлами, смысл которой покрыт более общей:
   "Animals/Kitten/" (1 файл) → Animals/Cats
   → folder, suggest, files

5. МИССПЛЕЙСМЕНТ (type: "misplaced_file")
   Файл противоречит тегам:
   "Technology/lion_photo.jpg" (lion, wildlife) → Animals/Wildlife
   → file, current, suggest

6. НЕСОГЛАСОВАННОСТЬ (type: "inconsistent")
   Одинаковые теги ведут в разные категории:
   "lion" в "Animals/Wildlife/" и в "Nature/"
   → tag, folders, suggest

━━━ ЧТО НЕ ПРОБЛЕМА ━━━
• "Animals/Birds/" и "Animals/Wildlife/" — нормальная иерархия.
• "Animals/Cats/" и "Animals/Wildlife/" — то же самое.
• "Food/FastFood/" и "Food/Nutrition/" — разные подкатегории.
• Пустые теги в "Unsorted/" — норма.
• Противоречивые теги в "Other/" — норма.
• Разные подкатегории внутри одной верхней — норма.

━━━ ДВА РЕЖИМА ОТВЕТА ━━━

Режим А — ТОЧЕЧНЫЕ ПРАВКИ (предпочтительно, если проблем ≤ 10):
{
  "ok": false,
  "issues": [ {...}, {...} ]
}

Режим Б — ПОЛНАЯ ПЕРЕСТРОЙКА (если правок > 10 или структура в целом плохая):
{
  "ok": false,
  "tree": ["Animals/Wildlife/owl.jpg", "Work/Finance/report.pdf", ...]
}
"tree" — то же самое, что на входе, но с исправленными путями.
Все файлы из входа должны присутствовать ровно по одному разу,
имена файлов — БЕЗ изменений, папки без пробелов, макс. 3 уровня.

Выбор режима:
• Если правишь 1–10 файлов → Режим А (issues).
• Если переделываешь >10 файлов или перестраиваешь иерархию → Режим Б (tree).

Если проблем нет:
{ "ok": true, "issues": [] }

    "current": "Other/OIP-2845334056.jpg", "suggest": "Animals/Birds",
    "reason": "owl — птица" }

Для inconsistent:

    "folders": ["Animals/Wildlife", "Nature/Wildlife"],
    "suggest": "Animals/Wildlife",
    "reason": "одинаковые теги в разных корнях" }

Правила полей:
- "from"/"to" — БЕЗ слэшей на конце
- "suggest" — полная категория БЕЗ имени файла
- "files"/"affected_files" — точные имена файлов или пути
- "file" — точное имя файла

Верни только JSON. Никакого текста до или после.
